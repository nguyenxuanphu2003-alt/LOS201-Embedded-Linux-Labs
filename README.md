## Lab 1 - Embedded Linux System

### Objective

Build a minimal Embedded Linux system using
Linux Kernel, BusyBox, U-Boot, and QEMU.

### Environment

- Linux Kernel 5.15.0
- BusyBox 1.35.0
- U-Boot 2022.04
- QEMU ARM Cortex-A9
- Target Board: vexpress-a9

### Features

- Linux Kernel compilation
- BusyBox root filesystem
- Initramfs creation
- U-Boot bootloader
- ARM emulation using QEMU

## Lab 2 - Linux Device Driver

### Objective

Develop a Linux character device driver and
explore Linux virtual filesystems.

### Features

- Character Device Driver
- Device read/write operations
- procfs interface
- sysfs interface
- NAND Flash simulation
- JFFS2 filesystem

### Development Environment

- Ubuntu Linux
- Linux Kernel 5.15
- ARM Cross Compiler
- QEMU
